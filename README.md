# Swift-mutants

Mutation testing for Swift.

## Installation

```sh
# Requires macOS 15 or later and Swift 6.3 or later.
git clone https://github.com/P4suta/swift-mutants.git
cd swift-mutants
swift build -c release
```

## Usage

```sh
.build/release/swift-mutants list
```
